# Court Hub — /public/models

Drop final `.glb` 3D assets here. The codebase will use these paths:

- `racket.glb` — featured HEAD/Wilson racket for the Shop section.
- `court.glb` — top-down padel court for the Build A Court section.
- `ball.glb` — lime padel ball for the Hero impact moment.

3D scenes degrade gracefully to static imagery on low-end mobile (`navigator.hardwareConcurrency < 4`).
